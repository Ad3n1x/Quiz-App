# QZ — Think fast. Prove it.

**QZ** is an interactive quiz experience built by **AD3N1X**. It combines quick knowledge checks, subject-based practice, daily challenges, custom quizzes, and a separate live multiplayer experience.

## Play

- **QZ website:** https://quiz-app-henna-omega.vercel.app/
- **Live multiplayer:** https://qz-live-web.onrender.com/
- **Source code:** https://github.com/Ad3n1x/Quiz-App
- **Developer portfolio:** https://portfolio-sandy-seven-w0bgdmliak.vercel.app/

## What you can do

- Take a daily general-knowledge challenge based on current news.
- Track personal daily challenge scores in the browser.
- View the online daily leaderboard when the service is available.
- Share a challenge link and invite friends to beat your score.
- Practise Math, Physics, and Chemistry.
- Create a custom quiz and let someone else take it.
- Host or join a live multiplayer quiz room using a room PIN through the separate QZ Live application.

## Technology

The main QZ experience is built with:

- HTML
- CSS
- Vanilla JavaScript
- Browser APIs for local progress, sharing, and network requests

The live multiplayer experience is deployed separately.

## Run locally

The main experience is a static web application. Clone the repository and open `index.html` in a browser, or serve the repository with a local static web server.

```bash
git clone https://github.com/Ad3n1x/Quiz-App.git
cd Quiz-App
```

Some features, including the online leaderboard and current-news daily questions, require the corresponding online service to be available.

## Project status

QZ is an independently developed learning and quiz project. Online services and multiplayer availability depend on their separately hosted backend.
